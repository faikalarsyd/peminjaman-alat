# Evaluasi

## Fitur yang disiapkan
Login/register/logout, tiga role, CRUD user/alat/kategori, peminjaman, approval, pengembalian, denda, stok, log aktivitas, laporan, pengaturan denda, profile, bantuan, tentang, responsive UI, stored procedure/function/trigger.

## Bug/pengujian yang belum dapat divalidasi otomatis
Apache + MySQL/MariaDB XAMPP tidak tersedia pada lingkungan pembuatan. Karena itu koneksi DB, import procedure/trigger, dan alur transaksi wajib diverifikasi di XAMPP target.

## Rencana pengembangan
Reset password nyata, notifikasi, export PDF, pagination AJAX, dashboard grafik, multi-item transaction UI, dan audit log lebih detail.
